# 单张图片预测调用说明

本文档说明如何使用已经训练好的二分类模型，预测一张瓶子图片是否有水或残留液体。

## 1. 预备

如果只是做单张图片预测，至少需要这些内容：

```text
A_liquid_detection/
├─ src/
├─ requirements.txt
├─ predict_one.ps1
└─ outputs/runs_bottle_final/binary_bottle_seed42_test25/models/
   ├─ best_model.joblib
   └─ scaler.joblib
```

其中：

```text
best_model.joblib = 训练好的二分类模型
scaler.joblib     = 训练时保存的特征标准化器，预测时必须配套使用
src/              = 特征提取和预测代码
requirements.txt  = Python 依赖库列表
predict_one.ps1   = 单张图片预测的便捷调用脚本
```

## 2. 安装依赖

打开 PowerShell，进入工程目录：

```powershell
cd E:\素衣叹风尘\浙江大学\数学建模\A_liquid_detection
```

安装依赖：

```powershell
pip install -r requirements.txt
```

## 3. 预测一张图，标注好了的

如果图片里基本只有瓶子，可以直接预测整张图：

```powershell
.\predict_one.ps1 -Image "E:\图片路径\test.jpg"
```

等价于直接调用 Python：

```powershell
python src\predict_image.py --image "E:\图片路径\test.jpg" --run_dir outputs\runs_bottle_final\binary_bottle_seed42_test25
```

## 4. 预测一张完整原图，并手动指定瓶子框

如果图片是完整场景图，需要手动给出瓶子的矩形框：

```text
xmin ymin xmax ymax
```

例如：

```powershell
.\predict_one.ps1 -Image "E:\图片路径\test.jpg" -Bbox 954,187,2102,3812
```

等价于：

```powershell
python src\predict_image.py --image "E:\图片路径\test.jpg" --bbox 954 187 2102 3812 --run_dir outputs\runs_bottle_final\binary_bottle_seed42_test25
```

注意：当前模型不负责自动检测瓶子位置。如果输入完整原图但不给 `bbox`，脚本会把整张图当成瓶子区域，结果只能作为粗略参考。

## 5. 输出结果

脚本输出示例：

```text
image: E:\图片路径\test.jpg
bbox: full image used
model: LogisticRegression
prediction: 1 (has_liquid)
probability_has_liquid: 0.9352
```

含义：

```text
prediction: 1 = 有水或有残留液体
prediction: 0 = 无水或空瓶
probability_has_liquid = 模型判断为有水的概率
```

## 6. src 关键代码作用

```text
src/predict_image.py
```

单张图片预测入口。它读取图片，按需要裁剪 bbox，提取传统图像特征，加载 `best_model.joblib` 和 `scaler.joblib`，最后输出预测结果。

```text
src/features_traditional.py
```

传统图像特征提取代码。会把瓶子图像转成固定长度的 851 维特征，包括颜色、灰度、纹理、边缘、Hough 候选液面线等信息。

```text
src/preprocess.py
```

图像预处理代码。负责读取图片、按照 bbox 裁剪瓶子区域、保存裁剪图。

```text
src/config.py
```

工程路径和基础参数配置，例如默认数据目录、输出目录、特征图像尺寸等。

```text
src/run_pretest.py
```

二分类训练主入口。如果队友要重新训练模型，就运行这个脚本。

```text
src/train_eval.py
```

二分类训练和评估核心代码。负责划分训练集/测试集、训练 LogisticRegression/SVM/RandomForest、计算指标、保存模型和图表。

```text
src/dataset.py
```

读取标注 CSV，检查图片路径，按照标注框生成瓶子 crop。

```text
src/visualize.py
```

生成论文可用图，例如混淆矩阵、模型指标对比图、特征二维可视化图。

## 7. 最小理解版流程

单张预测的内部流程是：

```text
输入图片
  -> 如果给了 bbox，就先裁剪瓶子区域
  -> 提取 851 维传统图像特征
  -> 用 scaler.joblib 做标准化
  -> 用 best_model.joblib 做二分类预测
  -> 输出是否有水和概率
```

所以模型文件不能脱离 `src` 单独使用， `src` 负责把图片变成模型能读懂的特征向量。
